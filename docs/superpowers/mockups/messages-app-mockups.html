Messages App — 4 interactive mockups

All four run the same fake data and the same rules as the game. Things to try in each: tap Vorn (new text) → ACCEPT → pick a window → watch the meetup countdown + "marker added to compass". Or COUNTER: try 95 (they take it — price locks, you can only pick a time), 110 (they counter back — take it or walk), 150 (refused, deal dead). Skell has a deal already running. Tap any buyer's name in a thread for their contact card (the learned hidden wants). Bond is always labelled.

A — SCANNER

The game's existing HUD language: flat cyan, corner brackets, scanlines. Zero new visual vocabulary to learn.

B — BUBBLE

Modern messenger, Schedule-1 adjacent: avatars, round bubbles, big friendly reply pills. Most readable at a glance.

C — TERMINAL

Retro pager/CRT: monospace green phosphor, blinking NEW, replies as command options. Simplest to build, strong flavor.

D — DEAL BOARD

Deal-first: open the app and the deals ARE the index — accept/haggle/pass without ever opening a thread. Fastest loop.
